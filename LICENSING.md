# What the licence covers

The port's own code is released under the **MIT licence** ([LICENSE](LICENSE)). This page says which parts of the
repository that is, and which parts it is not.

## Covered by MIT

Everything written for the port, unless a section below says otherwise:

- the platform layer and host adapter (`src/native`, `src/b3host`, `src/audio`, `src/port`, `include/b3host`,
  `include/b3hw`, `include/b3compat`, ...);
- the renderer and its tools (`src/b3replay`, `src/b3gfx`, `src/b3asset`, `src/gameview`, `src/b3view`);
- the launcher, PC settings, bug reports and run logs (`src/b3launcher`, `src/b3settings`, `src/b3report`);
- the mod loader, `b3modtool` and the mod kit (`src/b3mod`, `src/b3modtool`, `tools/modding`, `examples/mods`);
- the **mod SDK** headers and templates (`sdk/`). Because they are MIT, a mod built with them may use any licence
  its author chooses;
- the generator and every other tool (`tools/`), the tests (`tests/`), the configuration (`config/`), the build files
  and the documentation (`docs/`).

## Not covered by MIT

**The game.** Burnout 3: Takedown, its code, data, names and logos belong to their owners. No game data, assets or
disc files are in this repository; to play you need your own copy of the game, which the port reads and never changes.

**`gen/`: code generated from the game.** `gen/` holds C++ generated by `tools/decomp2host` from a decompilation of the
game's executable. It is the game's own code in another form and remains the property of its owners. It is in the
repository so the port builds without a decompilation checkout; it is not offered under MIT, and this project grants
no licence to it.

**`src/libs/`: the libraries linked into the game.** Behaviour-equivalent C for the RenderWare, RenderWare Audio,
Sony and Logitech library code that the game's executable contains, written from that executable's code. Like `gen/`,
it is the game's code in another form, belongs to its owners and is not offered under MIT.

**The game's logo.** `docs/logo.png` and the B3 icon in `assets/` show the game's name and logo, which are trademarks
of their owners; they are not offered under MIT.

**Third-party components** keep their own licences:

| zlib | linked (not in the repository) | zlib |

The release packages list what they ship in `tools/release/THIRD-PARTY-NOTICES.txt` (Windows) and
`THIRD-PARTY-NOTICES-linux.txt` (Linux), with the licence texts in `tools/release/licenses/`.
